# Portuguese Bank Marketing ML Project

## Overview
A machine learning project that predicts whether a bank customer will subscribe to a term deposit following a marketing campaign.

## Business Objective
Identify potential customers more effectively and support data-driven marketing decisions.

## Dataset
- `bank-additional-full.csv`
- Target variable: `y` (yes/no)

## Project Steps
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and comparison
- Classification metrics and threshold analysis
- Business recommendations

## Models
- Logistic Regression
- Random Forest
- Extra Trees
- Decision Tree

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## How to Run
1. Download both project files.
2. Install the required libraries: `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
3. Open `portuguese_bank_marketing.ipynb` in Jupyter Notebook.
4. Keep the CSV in the same folder and run the notebook cells in order.

## Note
This dataset is historical, and model performance may not generalize to current marketing campaigns. Call duration should be excluded from predictions made before a call.

## Project Type
Data Science and Machine Learning Capstone Project.
